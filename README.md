# Medical Insurance Cost Prediction

## Project Overview
This project explores medical insurance costs using
Python and machine learning.

The goal is to understand how factors such as age,
BMI, smoking status, and number of children
relate to medical insurance charges.

## Project Objectives
- Clean and explore insurance data
- Analyze relationships between variables
- Create visualizations using Python
- Predict medical insurance charges
- Evaluate machine learning models

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The dataset contains information about:
- Age
- Sex
- BMI
- Number of children
- Smoking status
- Region
- Medical insurance charges

## Project Files
- insurance_project.ipynb: Jupyter Notebook
- Medical insurance prediction np.py: Python script
- insurance.csv: Dataset

## Machine Learning
This project explores regression models to
predict medical insurance costs.
